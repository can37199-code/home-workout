# 오늘홈트

정해 둔 기간 동안 매일 맨몸운동을 하고 기록하는 개인용 PWA입니다. 서버가 없고, 모든 기록은 휴대폰 브라우저(localStorage)에만 저장됩니다.

## 기능
- **챌린지 설정**: 기간(14/30/60일, 직접 입력), 수준(입문·중급·상급), 체중 목표, 운동 시간
- **날짜별 루틴**: 하체 → 상체·코어 → 전신 유산소 순서로 돌고, 7일째는 가벼운 회복 데이. 매주 횟수가 8%씩 늘어남
- **아바타 플레이어**: 코드로 그린 관절 애니메이션이라 속도를 자유롭게 조절할 수 있음
  - *내 속도 맞춤(탭)*: 1회 할 때마다 탭하면 탭 간격을 학습해서 아바타 속도를 맞추고, 내가 느리면 아바타가 기다림
  - *자동 재생*: 0.5~1.6배속 슬라이더(동작별로 저장)
  - 음성 카운트(하나, 둘…), 세트 사이 휴식 타이머, 화면 꺼짐 방지
- **기록**: 달력에 완료/부분/놓친 날 표시, 연속 기록(스트릭), 전날 운동 보충하기, 컨디션·메모·체중
- **통계**: 달성률, 총 시간과 칼로리, 체중 그래프, 동작별 누적 횟수
- **알림**: 구글 캘린더 반복 일정 추가 또는 .ics 파일
- **백업**: JSON 파일로 내보내기/불러오기

## 구조
| 파일 | 역할 |
|---|---|
| `js/avatar.js` | 관절 아바타 엔진 (IK, 포즈 보간, 캔버스 렌더링) |
| `js/exercises.js` | 동작 12종의 키프레임과 자세 팁 |
| `js/plan.js` | 날짜별 루틴 생성과 칼로리 계산 |
| `js/player.js` | 운동 진행 (탭 페이스 학습, 세트, 휴식, 음성) |
| `js/store.js` | localStorage 저장, 날짜·스트릭 계산 |
| `js/app.js` | 화면 (홈, 기록, 통계, 설정, 완료) |
| `sw.js` | 오프라인 캐시 |

## 로컬 실행
```bash
node tools/serve.mjs
```
그다음 http://localhost:5180 에 접속합니다. `tools/gallery.html`에서는 모든 동작 애니메이션을 한 화면에 모아 볼 수 있습니다.

## 배포
GitHub Pages(main 브랜치 루트)로 배포합니다. 파일을 바꾸면 `sw.js`의 `VERSION`을 올려 주세요.

## 동작 추가하는 법
`js/exercises.js`에 `frames: [[시작비율, 포즈], ...]`를 추가합니다. 포즈의 팔다리는 각도 `[윗마디, 아랫마디]`로 주거나 IK 목표 `{ t: [x, y], bend: ±1 }`로 줍니다. IK를 쓰면 손발이 바닥에 고정됩니다. 각도는 0이 아래, 90이 앞, 180이 위입니다.
